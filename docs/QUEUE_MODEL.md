# Математическая основа SmartQ

## Источники и границы заимствования

1. Dean J., Goldberg E., Michor F. (2022). Designing optimal allocations for cancer screening using queuing network models. PLOS Computational Biology 18(5), e1010179. DOI: https://doi.org/10.1371/journal.pcbi.1010179. Раздел Mathematical background, печатные страницы 4–5.
2. Ucar I., Chukova S. (2018). Queueing Systems M/M/1 and M/M/c: https://homepages.ecs.vuw.ac.nz/~schukova/SCIE201/Lectures/Lecture9_final2018.html, раздел The M/M/c system.

Статья [1] моделирует состояния заболевания и переходы между ними, преимущественно сетью M/G/∞. Ее модель не является готовой моделью ожидания у конечного числа аппаратов. SmartQ использует закон Литтла и отдельно обозначенную адаптацию M/M/c из теории очередей [2]. Это операционная модель, а не воспроизведение исследования выживаемости.

## Три формулы с изображения

### 1. Отношение λj / μj

В статье ρj = λj/μj — средняя численность в узле с неограниченным числом ресурсов. Здесь не требуется ρj < 1. Нельзя интерпретировать это число как процент занятости одного аппарата.

Для клиники с c одинаковыми параллельными ресурсами используем ρ = λ/(cμ). При c=1 получаем отношение с изображения. Для стационарной M/M/c требуется ρ < 1. При выполнении условий модели ρ — средняя доля занятости ресурса. При ρ≥1 отношение отражает недостаток мощности, а стационарные средние ожидания не существуют.

### 2. E(W*) = E(N*) / η

Это закон Литтла для одной и той же границы системы: средняя численность / пропускной поток. В статье речь идет о времени в сети состояний заболевания; его нельзя автоматически назвать ожиданием у кабинета.

В SmartQ для одной услуги:

- Q — только ожидающие, N — ожидающие и находящиеся на обследовании;
- Lq = E(Q), L = E(N), средние за время, не мгновенные снимки;
- Wq = Lq/λ × 60 — ожидание в минутах;
- W = L/λ × 60 = Wq + 60/μ — ожидание и обследование;
- при λ=0 закон с делением не применяется; интерфейс явно использует предельные значения Wq=0, W=60/μ для гипотетического поступающего пациента.

### 3. P(N*1>x) = exp(-a) × Σ[k=⌊x⌋+1..∞] a^k/k!

Это следствие пуассоновского распределения численности узла M/G/∞, описанного на стр. 4–5 статьи. В основном тексте оно не выделено как самостоятельная третья формула. a=λ1/μ1. Подстановка a=η1/μ1 допустима, если в узел нет внутренних поступлений. Иначе необходимо решить уравнения трафика λ=η+λR.

Данная вероятность не является риском переполнения очереди к конечному числу аппаратов. Для прозрачности исходная формула реализована отдельной проверкой на странице `/methodology`, с явным обозначением M/G/∞.

## Расчет клинической очереди

Одна общая очередь, c одинаковых параллельных ресурсов, независимые экспоненциальные длительности и постоянный пуассоновский поток. Нет ухода из очереди, отказов, приоритетов, перерывов и блокировки следующими этапами. Ресурс означает доступный одновременно комплект аппарата, кабинета и сотрудника одной услуги. Разные исследования и аппараты нельзя считать взаимозаменяемыми.

Обозначим a=λ/μ и ρ=a/c.

```text
p0 = 1 / (Σ[k=0..c−1] a^k/k! + a^c/(c! × (1−ρ)))
C = p0 × a^c / (c! × (1−ρ))
Lq = C × ρ/(1−ρ)
L = Lq + a
Wq = Lq/λ × 60
W = L/λ × 60
```

C — вероятность того, что поступающему пациенту придется ждать (Erlang C). Реализация вычисляет C устойчивой рекурсией через Erlang B, избегая переполнения факториалов; полученное значение эквивалентно приведенной формуле.

Для целого x≥0 событие Q>x означает не менее x+1 ожидающих. У M/M/c для n≥c имеем P(N=n)=P(N=c)ρ^(n−c). Суммирование геометрического хвоста от n=c+x+1 дает:

```text
P(Q>x) = C × ρ^(x+1).
```

Это вероятность превышения в стационарный момент, а не вероятность хотя бы одного переполнения за день и не факт текущего переполнения. При ρ≥1 интерфейс не показывает фиктивные 100%: стационарный риск недоступен.

Среднее число занятых ресурсов равно a, среднее свободных — c−a при устойчивой системе. Это не наблюдаемое количество свободных кабинетов в конкретную минуту.

## Откуда брать входные данные

- λ: фактические поступления выбранной услуги / часы наблюдения. Не считать отмененные записи и неявки фактическими поступлениями. Входящие направления учитывать в суммарном потоке.
- s: среднее время занятия ресурса, включая обязательную подготовку и оборот. μ=60/s при s в минутах.
- c: одновременно работающие однотипные ресурсы. Учитывать смены, отсутствие сотрудников и простои.
- x, допустимое ожидание и риск: согласованные с клиникой цели, а не нормативы статьи.
- Для проверки Lq: площадь под графиком Q(t), деленная на длительность наблюдения. При смене состава услуг или времени дня данные нужно разделять.

Текущие параметры центров — демонстрация одной условной однородной услуги. Они не являются измерениями учреждений Актау. `inQueue` — отдельный демоснимок; он не подставляется вместо среднего Lq.

Строки прогноза по часам рассчитаны как независимые стационарные сценарии. Они не переносят накопленную очередь между часами и не являются подтвержденным прогнозом расписания.

## Управленческие решения и экономика

Подбор числа ресурсов перебирает c и выбирает минимальное устойчивое значение, удовлетворяющее заданным ограничениям Wq≤Wmax и P(Q>x)≤Pmax. Это решение только внутри явно заданной модели и диапазона поиска, не доказательство глобального оптимума работы учреждения.

Цвета карты — настройка интерфейса: низкая нагрузка при ρ<0.65, средняя при 0.65≤ρ<0.85, высокая при ρ≥0.85. Эти границы не взяты из статьи и не являются медицинским нормативом.

Персональный талон имеет другую границу: назначенный кабинет. Оценка работы перед пациентом = число пациентов впереди × 60/μ + добавленная сотрудником задержка. Это простая оценка ожидаемой работы, не стационарный прогноз и не гарантированное время. Демонстрационный диапазон вокруг нее не является доверительным интервалом.

Экономический калькулятор использует отдельные балансовые равенства: дополнительные визиты × длительность / 60 = возвращенные часы; количество × стоимость единицы = оценка ресурсов или затрат. Снижение неявок, доля возвращенных визитов, цены и экономия времени регистратуры — сценарные допущения. Их не доказывают ни теория очередей, ни статья [1]. Ресурсная ценность и условный срок покрытия ресурсами не равны денежной экономии или финансовой окупаемости.

## Проверка до внедрения

Собрать обезличенные события прибытия, начала и окончания процедур и доступность ресурсов. Проверить постоянство потоков по выбранным интервалам, зависимость и распределение длительностей, приоритеты и уходы. Сравнить прогноз с фактическими средними ожиданиями на независимом периоде. Если предположения не выполняются, выбрать другую модель или имитацию. Точность алгебры внутри модели сама по себе не подтверждает точность прогноза клиники.

Проверки реализации охватывают известные M/M/1 и M/M/2 решения, закон Литтла и единицы, нулевой поток, перегрузку, строгий порог хвоста, пуассоновские значения против высокоточной десятичной арифметики, выбор ресурсов и согласованность показателей центров.
