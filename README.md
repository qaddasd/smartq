# SmartQ Health

Прототип системы записи на онкоскрининг и управления очередями для медицинских учреждений Актау и Мангистауской области.

## Возможности

- Запись, перенос и отмена посещений; локальные напоминания.
- Карта медицинских центров и электронная очередь с QR-регистрацией.
- Расчёт нагрузки, ожидания и риска длинной очереди по модели M/M/c.
- Подбор количества параллельных ресурсов под заданные цели ожидания и риска.
- Научное обоснование формул, экономический калькулятор и план пилота.
- Демонстрационная панель сотрудника и аналитика.
- Раздел о скрининге с источниками NHS / WHO, пример напоминания с подтверждением и переносом.
- Русский и казахский языки, адаптивная тёмная тема, собственные SVG-иконки.

## Запуск

Нужны Node.js 24 и npm.

```sh
npm ci
npm run dev
```

Откройте адрес, который выведет сервер; в текущей конфигурации — `http://localhost:8080`.

## Проверки и сборка

```sh
npm run typecheck
npm run test:unit
npm run build
```

При обычной локальной сборке Nitro создаёт каталог `.output` для Cloudflare Module. На Vercel платформа определяется автоматически: сборка создаёт `.vercel/output` со статическими файлами и серверной функцией Node.js 24. Команды для Vercel: установка — `npm ci`, сборка — `npm run build`; каталог результата определяется через Nitro Build Output API.

`package-lock.json` содержит платформенные зависимости для Windows, Linux и macOS. После обновления зависимостей проверяйте `npm ci` в чистом каталоге: файл, пересозданный рядом с существующим `node_modules`, может потерять записи для других платформ.

## Данные и границы прототипа

Показатели центров и расписание демонстрационные. Записи сохраняются в браузере, не передаются в клиники и не бронируют реальные приёмы. Общий сервер, авторизация сотрудников, интеграции с медицинскими системами и внешняя отправка SMS / WhatsApp / Telegram пока не подключены.

Напоминания за 72, 24 и 2 часа проверяются, пока сайт открыт. Поздно созданная запись не получает уже прошедшие напоминания; при возвращении на сайт показывается только последнее актуальное, без повторной доставки. Отмена исключает запись из рассылки и освобождает слот. Календарный файл содержит будущие сигналы за 72, 24 и 2 часа и сигнал перед визитом; их показ зависит от календаря и разрешений телефона. После переноса или отмены нужно обновить событие в календаре вручную.

Для проверки камеры откройте `/scan` по HTTPS (или localhost), нажмите «Включить камеру» и разрешите доступ. Отказ, отсутствие камеры и зависший запрос имеют отдельные сообщения. Видео не передаётся на сервер.

На Vercel команда сборки дополнительно проверяет ответ реальной серверной функции: клиентский скрипт должен ссылаться на существующий `/assets/…`, а не на служебный адрес Vite. Рабочая серверная обёртка находится только в `src/server.ts`; корневой `server.ts` перехватывал Nitro и ломал клиентскую загрузку.

Методика и источники формул описаны в [docs/QUEUE_MODEL.md](docs/QUEUE_MODEL.md). Экономические значения являются сценарными допущениями. Точность расчётов внутри модели не означает подтверждённую точность прогноза реальной клиники.

## Технологии и структура

React, TypeScript, TanStack Start / Router, Vite, Tailwind CSS, Leaflet и Nitro. Рабочий код находится в `src/`, публичные ресурсы — в `public/`, документация — в `docs/`. Маршруты определяются файлами `src/routes/`; `src/routeTree.gen.ts` генерируется автоматически.
